# IOS Project 1 – Shell Log/Data Analyzer

First project for the **IOS (Operating Systems)** course, written in POSIX Shell and AWK.

## Overview
A command-line utility script for parsing, filtering, and generating statistical summaries or ASCII histograms from structured text logs and data files.

## Usage
```bash
chmod +x <script_name>
./<script_name> [FILTERS] [COMMAND] [LOG_FILES...]
```
